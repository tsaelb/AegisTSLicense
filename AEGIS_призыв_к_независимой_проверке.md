# AEGIS — призыв к независимой проверке

*Рабочий материал. Публикуется вместе с проектом лицензии (О-2). Порядок проверки — В-6 и Приложение Ж, расчёт 11.*

## Что проверяется и зачем

Проект лицензии AEGIS не вступает в силу, пока по каждой области ниже не пройдёт круг из **8 новых независимых проверяющих**, которые не найдут ни одной новой существенной ошибки. Круги повторяются: найденное исправляется, следующий круг проводят другие люди.

Такой круг гарантирует только одно: ошибку, которую замечает хотя бы каждый третий проверяющий, он пропустил бы с вероятностью не больше 4%. Малозаметные ошибки могут остаться. Проект не утверждает, что ошибок нет (K-10).

| Область | Кто нужен | Главные вопросы |
|---|---|---|
| Русский текст | носители русского языка | однозначность, грамматика, нет ли двух прочтений, понятность без юриста |
| Английский текст | носители английского языка | то же для английского; естественность юридического стиля |
| Равнозначность языков | двуязычные читатели | говорят ли RU и EN одно и то же в каждом положении (K-0.11); особенно термины ниже |
| Математика моделей | статистики, специалисты по теории решений | допущения приложений А, Б, Д, Ж; сетки сценариев; критерии выбора; правильность формул |
| Криптография и система доверия | криптографы, специалисты по безопасности | В-1, В-4, В-7, В-11, В-12, П-13; Приложения Г, Е, З; постквантовые подписи; обновление хешей |
| Формальные модели | специалисты по формальной проверке | перевод ядра в формулы Z3; индуктивное доказательство Приложения В; полнота контрольных опытов |
| Логика ядра | любой внимательный читатель | противоречия, лазейки, обход защитных целей (K-0.5), несправедливость к ограничиваемому |

## Кто может проверять

- Любой человек — по открытому призыву. Автор текста проверяющих не выбирает.
- Независимость — по определению 21. У проверяющего не должно быть связей категорий 1–4 по У-5 с автором текста: работа или оплата, заинтересованная властная структура, личная связь. Связь заявляется по категориям, без названий и имён; вместо раскрытия можно взять самоотвод.
- Можно действовать под псевдонимом.
- Оплата от автора не принимается.
- Один человек может проверять несколько областей. В следующем круге той же области он уже не считается «новым».

## Как запустить всё самому

Нужны Python 3, `numpy`, `scipy`, `z3-solver`, `cryptography` (версия с ML-DSA).

```
python3 -I check_all.py <папка с файлами> kz3_core.py
```

Скрипт сверяет оба текста: число и порядок положений, определения, ссылки и числа. Затем он запускает все приложения и проверяет их ключевые выводы. Дальше идут Z3-проверка ядра с контрольными опытами и мутационная проверка испытаний Приложения З. Каждое приложение можно запустить и отдельно; допущения перечислены в начале каждого файла и в таблице допущений.

## Термины, где расхождение языков вероятнее всего

| RU | EN | На что смотреть |
|---|---|---|
| Распорядитель | Steward | не путается ли с хранителями каналов (channel keepers); Р-9 |
| Основание | Grounds | «основание» в бытовом смысле и в смысле определения 18 |
| Существенный | Material | одинаковый ли порог в обоих языках |
| Независимый | Independent | применение к каналам и источникам, а не только к людям |
| Добросовестный / Добросовестно получивший | Good Faith / Good-Faith Recipient | вина и знание — одинаково ли |
| Произведение / Произведение на основе | Work / Derived Work | объём: программы, созданные с инструментами AEGIS (K-0.8) |
| Передача / Предоставление через сеть | Transfer / Network Provision | внутри организации; через другие программы |
| Скрытый | Hidden | «не уведомлён заранее» и «представлен как иное» |
| Властная структура | Power Structure | входят ли военные и политические силы одинаково |
| Сведения о людях | Information about People | публичные, обезличенные, агрегированные |
| травить или выслеживать | harass or track | K-24: не сузился и не расширился ли запрет |
| произвольно — без основания и без независимой проверки | arbitrarily — without Grounds and without independent review | K-24 |
| Защитная мера | protective measure | что это не наказание (K-0.12) |

Регистр букв значения не меняет: определённый термин значит одно и то же при любом регистре и форме.

## Как сообщить о находке

1. В открытый журнал проверки: положение, цитата, в чём ошибка, предлагаемое исправление. Секреты и сведения о людях не публикуются.
2. Указывается область и оценка — существенная или несущественная (определение 19).
3. Каждая находка получает публичный ответ: исправлено, отклонено с обоснованием или оставлено открытым. Отклонение можно оспорить.
4. Проверяющий не обязан ничего находить. Запись «проверил область X, новых существенных ошибок нет» — полноценный результат, и он засчитывается в круг.

## Что уже проверено автоматически

Повторять это не нужно, а проверить правильность — нужно.

- Ядро без противоречий в пределах перевода в формулы (Z3; два контрольных опыта находят заложенные конфликты).
- Числа в тексте совпадают с выводами моделей; RU и EN совпадают по числам и структуре.
- Свойства чрезвычайных мер доказаны индукцией для любой длительности (Приложение В).
- Порядок выбора K-0.14 всегда даёт ответ; проверено перебором 88 641 набора.
- Система доверия реализована эталонно (Приложение З): 27 испытаний атак; все 13 намеренно ослабленных версий правил испытания обнаруживают.

Не проверено, потому что пока не существует: поведение компилятора и среды выполнения языка AEGIS (Т-1–Т-10, С-1–С-7).
